# Changelog

## 1.0.0 (2024-01-15)

### Added
- Initial release of WireForge MCP Vertical Server Bundle
- GitHub MCP Server: list repos, search issues, read PRs, create issues
- Slack MCP Server: search channels, read messages, post messages, list users
- Notion MCP Server: search pages, read databases, create pages, query databases
- Full Zod input validation on all tools
- Docker Compose configuration for building and testing
- Comprehensive README documentation for each server
